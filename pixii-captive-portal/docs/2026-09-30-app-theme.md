## Behavioral scope

- New immutable assets: `experience-v6.js`, `connected-v3.js`, `app-theme/v1/`.
- All older runtimes are retained byte-for-byte for existing pages.
- Connecting runtime only adds synchronized subtitle visibility. Completion, visibility accounting, refresh checkpoints, expiry handling and router polling are unchanged.
- Connected runtime locates the moved progress bar in the containing screen and focuses the online heading once, so assistive technology receives the success/redirect context without announcing every timer tick. It does not take focus from an already-focused control. Click-only browser handoff and five-visible-second same-window redirect are unchanged.
- HTTP changes only allow same-origin font loads and dispatch the new static asset paths through the existing ASSETS binding.
- No backend API/schema/authorization/consent policy, DNS, Pages, credentials or router-package changes. No production leads were created for verification.
